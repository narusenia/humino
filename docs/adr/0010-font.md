# ADR-0010: フォントは Allo を同梱する

- 状態: 採用
- 日付: 2026-11-18

## 決定

- [Allo](https://github.com/joshpuckett/allo)（SIL OFL 1.1）のフル版可変フォント `AlloVariable.woff2` を同梱する。軽量版は ROND が 50 に固定されているので使わない
- `font-variation-settings: "ROND" 0`（角ばった形）、`font-optical-sizing: auto`、`font-variant-numeric: tabular-nums`
- ウェイトは大きい数字 250、ラベルとタブ 350、選択中のタブ 450
- ダイアログは `data:` URL なので、フォントは base64 で HTML に埋め込む。`.ablx` に `OFL.txt` を同梱する

## 結果

- Allo の数字が tabular-nums に対応しているかは実装時に確かめる。対応していなければ数字だけ等幅にする工夫が要る
