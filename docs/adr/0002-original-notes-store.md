# ADR-0002: 元のノートを保存し、毎回そこからかけ直す

- 状態: 採用
- 日付: 2026-11-18

## 背景

ヒューマナイズを同じクリップに何度もかけると、ずれが積み重なる。開始位置はグリッドに戻せるが、ベロシティと長さには戻す先がない。

## 決定

- 適用するたびに、元のノートと出力したノートのハッシュを `storageDirectory` に JSON で保存する
- 次に適用するとき、現在のノートのハッシュが前回の出力と一致すれば、保存した元のノートから処理し直す。一致しなければ（手で編集された場合など）、現在のノートを新しい元データとみなす
- ハッシュはクリップを特定するキーを兼ねる。SDK にはセッションをまたいで安定するクリップ ID がないため
- ハッシュには `selected` を含めない
- 入力はクオンタイズ済みを前提とし、拍の位置の判定にはグリッドを使う

## 結果

- 何度かけ直しても「1 回分」の効果になる
- 保存ファイルが増え続けるので、古いものを消す仕組みが要る（v1 では件数上限で古い順に消す）
