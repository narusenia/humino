# ADR-0009: 配色

- 状態: 採用
- 日付: 2026-11-18

## 背景

参考にした Fors（Opal、Pivot、Tela）は、ほぼ黒の背景にアクセント 1 色、線のアイコン、大きな数字という作りである。紫をそのまま使うと Fors の製品に見えてしまう。

## 決定

- UI の枠（タブ、つまみ、ボタン）はアンバー `#E8A55A` の 1 色にする
- プレビューの中だけ、処理ごとの色を使う：Groove サーモン `#E07A6B`、Humanize アンバー `#E8A55A`、Strum セージ `#8FB98A`、Connect スカイ `#7FA7D9`
- プレビューでは、ノートを白っぽい色で描き、元の位置からのずれを処理ごとの色の線で積み重ねて示す。Connect で追加したノートはスカイ色で描く。開いているタブの処理だけ濃く、ほかは薄くする
- すべて CSS 変数にして、1 か所で差し替えられるようにする
- 文字に使う灰色は、WCAG のコントラスト基準を満たす `#8A8A8A` 以上にする（SDK のデザインガイドに従う）
