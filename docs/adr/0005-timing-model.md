# ADR-0005: タイミングの揺れは Drift と Jitter の 2 層にする

- 状態: 採用
- 日付: 2026-11-18

## 背景

人の演奏のずれは、少しずつ走って戻るゆっくりした揺れと、ノートごとの細かいずれが重なっている。ノートごとに独立したランダムだけでは、ざらついた揺れになる。

## 決定

- Drift：時間（拍）に対する平均回帰ランダムウォーク（Ornstein–Uhlenbeck 過程。大きさ ms、戻る速さ）。和音の並び順で 1 歩ずつ進めると、ノートが密集した所だけ急に揺れて不自然になるため、時間で計算する
- Jitter：ノートごとのガウス分布のずれ（ms）。表拍では弱く、裏拍や 16 分の位置では強くする
- 和音の構成音はまとめて動かす。和音の中のずれは Strum が担当する
- Drift はクリップ全体で計算し、選択範囲にだけ当てはめる（ADR-0007）

## 結果

- シード値が同じなら同じ曲線になる。UI では Drift の曲線をプレビューに重ねて描く
