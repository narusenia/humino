# ADR-0006: Strum の向きは腕の振り子で決める

- 状態: 採用
- 日付: 2026-11-18

## 背景

和音が出るたびにダウンとアップを交互にすると、休符を挟んだときにリズムと向きがずれる。

## 決定

- 開始位置が同じ 2 音以上を和音とみなす
- 腕は一定の細かさ（8 分か 16 分。裏の 16 分に和音があれば 16 分）で振り続けているとみなし、振りの表に当たる和音をダウン、裏をアップにする
- ダウンは低い音から、アップは高い音から鳴らす。アップでは低音側の弦を指定本数だけ省く
- 基準位置は「最初の音をグリッドに置く」を初期値とし、「真ん中の音をグリッドに置く」も選べる
- 各音は元の終わりを保つ（遅れて鳴った音ほど短くなる）。次の和音の開始から数 ms 重ねて切るのは、次の和音と ±4 半音以内の音だけにする。全部を切ると、伸ばしたい低音や和音の直後に別の和音がある所で、音が点のように短くなるため
- 向きの決め方は「自動」と「全部ダウン」を選べる。右クリックの Strum Down / Up で、選んだ和音の向きを固定できる
- v2 でギターボイシング（ADR-0014 以降）が入ったら、音の高さではなく弦の順で並べる。v1 から「弦の番号があれば使い、なければ音の高さ順」という作りにしておく

## 結果

- 「真ん中」を選ぶと、クリップ先頭の和音の最初の音が 0 拍より前に出ることがある。その場合は 0 に丸める
