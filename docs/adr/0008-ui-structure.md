# ADR-0008: ダイアログ 1 つにタブで機能を並べる

- 状態: 採用
- 日付: 2026-11-18

## 背景

SDK の UI は右クリックメニューとモーダルダイアログ（HTML）だけで、ダイアログは「閉じて値を返す」ことしかできない。音で試聴できない。

## 決定

- 右クリックメニュー（MidiClip）は次の 4 つだけにする：`humino…`、`humino: Re-apply`、`humino: Strum Down`、`humino: Strum Up`。プリセットはメニューに並べない
- ダイアログはヘッダー（モード、プリセット、シード値）、プレビュー、タブ（Groove / Humanize / Strum / Connect）、パラメータ列、フッター（対象ノート数、Cancel / Apply）の構成にする
- ダイアログも packages/core を import し、つまみを動かすたびに本番と同じ処理でプレビューを描き直す
- 値は数字の上下ドラッグで変え、ダブルクリックで初期値に戻す。詳細な設定は Advanced として折りたたむ
- ギター / ピアノのモードはヘッダーで切り替える。初期値はピアノ

- ダイアログは 960 × 720 px。プレビューは選択、ロック、手でのずらし、ベロシティの調整ができるピアノロールにする（右クリック → ノートを選ぶ → クリップを右クリック、という手間を減らすため）

## 結果

- ダイアログへのノートの受け渡しは `data:` URL への埋め込みを第一候補にする。大きすぎる場合は一時ファイルと `file:` に切り替える
