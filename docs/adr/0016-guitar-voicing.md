# ADR-0016: ギターボイシングは process() の前に置き換える処理にする

- 状態: 採用
- 日付: 2026-11-19

## 背景

ピアノのように打ち込んだ和音を Strum しても、ギターでは押さえられない形のまま鳴る。和音をギターの形（1 弦に 1 音）に置き換えたいが、置き換えると音の数と高さが変わる。ほかの処理は入力のノートと出力のノートを番号で対応させていて（手での変更、ダイアログの選択、MIDI Tools の note_id）、パイプラインの途中で音の数を変えるとこの対応が崩れる。

## 決定

- core の `voice()` を、`process()` とは別の前処理にする。`voicedBase(notes, params, tempo)` がギターモードでオンのときだけ置き換えたノートを返し、Extension、ダイアログ、MIDI Tools はその結果を `process()` に渡す
- 置き換えたノートは弦の番号（`string`、1 が 1 弦）を持ち、Strum は弦の順に鳴らす。SDK に渡す前に `string` を外す
- Extension が保存する元のノートは置き換える前のものにする。ダイアログでは置き換えたノートを番号の基準にし、選択はそれに合わせる
- MIDI Tools では置き換えたノートを新しいノート（note_id なし）として出す。統合版の Str ページに加えて、ボイシングだけをかける `humino Guitar Voicing` を作り、`humino Strum` からは外す

## 結果

- 既存の処理（Groove〜Connect）は、ボイシングのあるなしを知らずに済む
- ボイシングの設定を変えると、ダイアログの選択はクリップの選択に戻り、ノート単位の手での変更は音の高さが変わったノートから外れる
- スタンダードチューニングでは、E（40）より低いベースは 1 オクターブ上に移る
