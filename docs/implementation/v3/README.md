## 01 アーティキュレーションのノート

音源のキースイッチ（低い音域に置いて奏法を切り替えるノート）は、揺らしたり伸ばしたりすると奏法の切り替えがずれる。和音の判定や Strum、Connect に混ざっても困る。

- 見分け方：音程の範囲で指定する（例：C-2〜B0）。範囲より上は今までどおり処理する
- 動かし方を 2 つから選ぶ
  - 追従：直後に鳴るノートの開始位置が動いた分だけ一緒に動かす。キースイッチがノートより少し前にある場合は、その間隔を保つ
  - 固定：一切動かさない
- キースイッチはどの処理の対象にもせず、和音、Strum、Connect、ボイシングの判定にも入れない

決めること
- 範囲の初期値と、範囲以外の見分け方（チャンネル、長さ）が要るか
- 「直後に鳴るノート」が和音や Strum で広がっているとき、どの音に合わせるか（最初に鳴る音が候補）

## 02 Brass モード

Guitar と Piano に並ぶ 3 つ目のモードにする。Strum と疑似ペダルは使わない。

候補
- セクションの揃い方：同時に吹く音を、奏者ごとに少しずつずらす
- アタックの遅れ：音の立ち上がりが遅い分、少し前に置く
- ブレス：休符の前やフレーズの切れ目で、ノートを短くして息継ぎの隙間を作る
- レガートの重なり：レガート奏法の音源向けに、次の音へ少し重ねる

決めること
- 上の候補のどれを入れるか
- Extensions SDK は CC を書けないので、CC1 や CC11 の強弱は入れられない。ベロシティだけで足りるか

## 03 プレビューで音を鳴らす

ダイアログの中で、処理前と処理後を耳で比べられるようにする。Live の音源は鳴らせないので、ダイアログの中で Web Audio の簡単な音を鳴らす。

- 再生、停止、ループと、処理前と処理後の切り替え
- 再生位置をプレビューに線で出す

決めること
- Live のダイアログ（WebView）で Web Audio が鳴るか。鳴らなければ 03 はやめる
- 音色（サイン波だけか、ピアノやギターに近い音か）

## 04 ピアノロールに近づける

今のプレビューでできるのは、選択、⌥ ドラッグでの位置の調整、ベロシティのドラッグ、Lock。ここにノートの追加、削除、音程と長さの変更を足す。

決めること
- 編集を元のノートに入れるか、今の手での変更（Overrides）のように処理後に重ねるか。元のノートに入れると、保存してある元のノートとの照合（ADR-0002）が変わる
- 03 の再生とあわせて、どこまで Live のピアノロールに寄せるか
