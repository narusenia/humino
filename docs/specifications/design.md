# humino 設計仕様

humino は MIDI クリップのノートを書き換えるヒューマナイザーである。この文書は処理の仕様、パラメータ、UI を定める。決定の理由は `docs/adr/` にある。

## 前提

- 対象：Live 12 Suite、Extensions SDK 1.0.0（Live 12.4.5 ベータ以降）
- 入力はクオンタイズ済みの MIDI クリップ（ADR-0002）
- 時間の単位：人の揺れ（Drift、Jitter、Strum）は ms、ノリ（Groove、Swing）はステップ長に対する %（ADR-0003）。ms から拍への変換には適用時の `Song.tempo` を使う
- 拍子は 4/4 を前提に作り始める。ほかの拍子の扱いは未定（下の「未決事項」）

## 全体の流れ

1. 右クリックのコマンドを受ける
2. クリップのノートを読み、保存してある元のノートと照合する（ADR-0002）
3. 処理対象を決める（ADR-0007）
4. ギターモードでボイシングがオンなら、先に和音をギターの形に置き換える（v2、ADR-0016）
5. パイプラインを通す（ADR-0004）：Groove → Humanize → Strum → 疑似ペダル → Connect（v2）。Groove、Humanize、Strum はそれぞれ on / off を持ち（初期値 on）、off の処理は飛ばす。前の版で保存した設定は on として読む
6. `withinTransaction` の中でクリップのノートを書き換え、元のノートと出力のハッシュを保存する

パイプラインは `packages/core` の純粋関数で、`(notes, params, context) => notes` の形にする。`context` はテンポ、拍子、スケール、シード値を持つ。ダイアログのプレビューも同じ関数を呼ぶ。

## 元のノートの保存

- 保存先：`storageDirectory/originals.json`
- 中身：出力ノートのハッシュ → `{ original: Note[], savedAt }`
- ハッシュは pitch、startTime、duration、velocity、muted、probability、velocityDeviation、releaseVelocity から作る。`selected` は含めない
- 適用時、現在のノートのハッシュがあればその `original` を元データにする。なければ現在のノートを元データにする
- 件数の上限は 500。超えたら `savedAt` が古い順に消す

## 和音の判定

開始位置の差が chord window（0〜50 ms、初期値 5 ms）未満で 2 音以上あるものを和音とする。差は和音の最初の音から測る。手で弾いた和音のようにグリッドから少しずれていても、chord window を広げれば 1 つの和音として扱える。拍の上かどうかの判定も、同じ幅だけずれを許す。和音の最低音をベース、最高音をトップと呼ぶ。chord window はダイアログのヘッダーで変える（上下ドラッグ、ダブルクリックで初期値）。

プレビューの上の段に、2 音以上の和音のコード名を出す（C、Am7、C/E など）。根音は最低音から順に試すので、最低音が根音になれる形があればそちらを選び、なければ転回形（分数コード）にする。5 度を省いた形も認める。Scale Mode がオンのときは、Live のキーの主音に対するディグリー（I、vi、V7、bVII など。マイナー系は小文字）を添える。知らない形の和音には何も出さない。

## Groove

| パラメータ | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| steps | 16 固定（v1） | – | 1 小節を 16 分で 16 ステップに分ける。3 連グリッドのクリップでは 12 ステップ。3 連の位置の音が 16 分の位置の音より多い時だけ 3 連グリッドとみなす（3 連グリッドでは swing をかけない） |
| timing[i] | −50〜+50 % | 0 | ステップ i のノートのずれ（ステップ長に対する %） |
| velocity[i] | −40〜+40 | 拍のアクセント | ステップ i のノートのベロシティ増減 |
| swing | 0〜75 % | 0 | 裏のステップを後ろへずらす。timing 表への上乗せ |
| swing grid | 8 分 / 16 分 | 16 分 | swing をかける細かさ。16 分では 16 分の裏だけが動き、8 分の裏の音は動かない |

velocity の初期値は拍のアクセントにする：1 拍目 +8、3 拍目 +4、2・4 拍目 0、8 分の裏 −4、16 分の裏 −8。

ノートの開始位置から最も近いステップを求め、そのステップの値を当てる。

### 別のクリップからの抽出（v2）

- 右クリックの `humino: Extract Groove` で、そのクリップのノリを抜き出して `storageDirectory/groove.json` に保存する。保存するのは最後に抜き出した 1 つだけで、クリップ名と 3 連グリッドかどうかも残す
- 和音ごとに最も近いステップを求め、ステップごとに平均する。timing はグリッドからのずれ（ステップ長に対する %、−50〜+50）、velocity は和音の平均ベロシティとクリップ全体の平均の差（−40〜+40）。音が無いステップは 0
- 和音の判定には、前回使った設定（`last.json`）の chord window を使う
- ダイアログの Groove タブの「『クリップ名』の Groove を読み込む」で、timing と velocity の表を置き換える。swing は変えない。抜き出したクリップと 3 連グリッドかどうかが違うときは、注意を出したうえで読み込む

## Humanize

### タイミング（ADR-0005）

| パラメータ | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| drift | 0〜40 ms | 8 | ゆっくりした揺れの大きさ |
| drift return | 0〜1 | 0.3 | 中心へ戻る速さ（Advanced） |
| jitter | 0〜20 ms | 4 | 和音ごとのずれの標準偏差 |
| spread | 0〜20 ms | 3 | 和音の中の音を 1 つずつずらす量の標準偏差。0 にすると和音の音はそろって動く |
| beat weight | 0〜100 % | 50 | 表拍で jitter を弱める割合。拍の頭では jitter × (1 − beat weight)、16 分の裏では jitter × 1 |

Drift は時間に対する平均回帰ランダムウォーク（Ornstein–Uhlenbeck 過程）で、クリップ全体について和音とノートの開始位置（拍）で計算する。ノートの密度に関係なく同じ速さで揺れる。drift return は戻るまでの時定数 τ =0.5 + (1 − drift return) × 8 拍に対応する（初期値 0.3 で約 6 拍）。和音の構成音は同じ drift と jitter を受け、そこに音ごとの spread が加わる。Guitar では Strum が和音の中の時間を決め直すので、spread は実質ピアノ向けになる。古い版で保存した設定に spread が無い時は、初期値で補う。開始位置が 0 拍より前になったら 0 にする。

### ベロシティ

| パラメータ | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| vel jitter | 0〜30 | 6 | ノートごとのランダムな増減（一様分布 ±） |
| chord balance | 0〜100 % | 40 | 和音のトップを強く、ベースをやや強く、中の音を弱くする度合い。100 % でトップ +12、ベース +6、中の音 −6 |

結果は 1〜127 に収める。

### 長さ

| パラメータ | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| legato | 0〜100 % | 0 | 次のノートとの隙間を詰める割合。100 % で次のノートの開始にぴったりつなぐ |
| length jitter | 0〜30 % | 5 | 長さのランダムな増減（元の長さに対する %） |

長さの最小値は 1/64 拍。同じ音程の次のノートと重なる場合は、次のノートの開始で切る。

## Strum（ギターモードのみ、ADR-0006）

| パラメータ | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| direction | auto / all down | auto | 向きの決め方 |
| motion | auto / 8 分 / 16 分 | auto | 腕の振りの細かさ。auto は 16 分の裏に和音があれば 16 分 |
| down speed | 0〜120 ms | 30 | ダウンで最初の音から最後の音までの時間 |
| up speed | 0〜120 ms | 20 | アップの同じ時間 |
| speed jitter | 0〜50 % | 15 | 和音ごとの速さの揺れ |
| taper | 0〜30 | 8 | 後から鳴る弦ほどベロシティを下げる量（最後の弦での合計） |
| up skip | 0〜3 本 | 1 | アップで省く低音側の弦の数。前のストロークで同じ音が鳴っていれば、その音を伸ばして省いた音は消す。鳴っていなければ和音の音として残す |
| anchor | first / center | first | グリッドに合わせる音 |
| overlap | 0〜20 ms | 5 | 次の和音の開始より後まで前の和音を残す時間 |

- ダウンは低い音から、アップは高い音から鳴らす。弦の番号がノートに付いていれば（v2 のボイシング）その順を使う
- 各音は元の終わりを保つ。遅れて鳴った音ほど短くなる
- 次の和音の開始 + overlap で、前の和音のうち次の和音が同じ音を弾き直す音だけを切る（次がアップで省く音は切らない）。それ以外は元の終わりまで鳴らす
- Strum Down / Up コマンドは、選んだ和音の direction をその和音だけ固定して、ほかのパラメータは前回の設定を使う。固定した向きは元データと一緒に保存し、ダイアログからの再適用でも保つ
- ダイアログの Strum タブでは、プレビューの各和音の上に向き（↓ / ↑）を出す。クリックするたびに 自動 → ダウン固定 → アップ固定 → 自動 と切り替わる。固定した和音の数と、すべて解除する Clear ボタンを Strum タブに置く
- motion が auto のとき、クリップに 16 分の位置の和音が 1 つでもあれば 16 分の振りになり、8 分の裏の和音もダウンになる

## 疑似ペダル（ピアノモードのみ）

| パラメータ | 範囲 | 初期値 | 内容 |
|---|---|---|---|
| pedal | off / bar / chord | off | ノートを伸ばす区間 |

区間の中で始まったノートを、区間の終わりまで伸ばす。chord はベースの音程が変わるところを区間の境目にする。同じ音程が区間の中で再び鳴る場合は、そこで前のノートを切る。

## Connect（v2）

| 対象 | 種類 | パラメータ | 初期値 |
|---|---|---|---|
| ベース | passing（経過音） | 確率 0〜100 % | 30 % |
| ベース | chromatic run | 確率 0〜100 %、段数 1〜6、方向 auto / up / down、in scale / chromatic | 30 %、2、auto、in scale |
| トップ | grace（前打音） | 確率 0〜100 %、1 音の長さ 1/64 / 1/32 / 1/16 拍、段数 1〜6、in scale / out | 20 %、1/32、1、in scale |
| 3 種類それぞれ | on / off、ベロシティ 0〜100 % | off、80 % |

- 経過音、chromatic run、前打音はそれぞれ on / off とベロシティを持つ。on / off の初期値は off で、前の版で保存した設定やプリセットでノートが増えないようにする
- 隣り合う 2 つの和音（単音も含む）のあいだに入れる。両方とも処理対象のときだけ入れる。和音から単音、単音から和音へ変わるところは同じ声部と言えないので入れない。ベースは鳴っている一番低い音、トップは一番高い音
- 前のノートの末尾を削って、そこに置く。全体の長さは変えない
- 次の音まで 8 分未満のときは入れない。1 段は 16 分で、前のノートに間の半分は残す。段数ぶんの余裕がなければ入る段数まで減らす
- ベースでは chromatic run を先に抽選し、外れたら経過音を抽選する
- chromatic run は次のベースへスケール音ずつ近づく。chromatic を選んだときとスケールがないときは半音ずつ近づく。auto は前のベースのある側から近づく（同じ高さなら下から）
- 経過音は前と次のベースのあいだにあるスケール音のうち、真ん中に一番近い音にする。あいだにスケール音がなければ入れない
- 前打音はトップの直前に置き、段数ぶん下からスケール音ずつトップへ上がる。out を選んだときとスケールがないときは半音ずつ上がる。間の半分に入らなければ入る段数まで減らす
- 足した音のベロシティは、経過音と chromatic run が前のベースの、前打音が次のトップのベロシティに、それぞれのベロシティの % をかけた値
- 処理の順は疑似ペダルの後、手での変更の前
- 経過音はスケール（`Song.rootNote`、`Song.scaleIntervals`）から選ぶ。Scale Mode がオフのときは経過音を出さず、chromatic run だけにする

## ギターボイシング（v2）

- ギターモードでオンのときだけ、Groove より前に置き換える（ADR-0016）。初期値はオフ
- 処理対象の 2 音以上の和音だけを置き換える。単音と、押さえ方が見つからない和音はそのまま残す
- 1 本の弦に 1 音、押さえる範囲は 4 フレット以内、開放弦を使ってよい。弾かない弦は端だけ（間を空けるとストロークできない）。2 本の弦に同じ高さの音を置かない（MIDI では片方がもう片方を切る）
- 一番低い音は元の和音のベースと同じ音名にする。元の和音の音名はすべて鳴らす（5 音名以上なら 1 つ欠けてよい）。少なくとも 3 音（元が 2 音なら 2 音）
- 候補の点数：トップの音程差 × 3 ＋ ベースの音程差 ＋ 手の移動（前の和音とのポジション差 × 1.5、最初の和音はポジション × 0.2）＋ 押さえる幅 × 0.5 − 鳴らす弦の数 × 1.2。小さいほど良い
- チューニング：Standard、Drop D。カポ 0〜7（開放弦がその分上がる）。ギターの最低音より低いベースはオクターブ上に移る
- 置き換えた音は、元の和音で音の高さが一番近いノートから長さとベロシティを受け継ぎ、弦の番号を持つ。Strum はその順に鳴らす
- Extension は保存する元のノートを置き換える前のものにするので、あとからボイシングを変えられる。ダイアログのプレビューは置き換えた後のノートで描き、ボイシングの設定を変えると選択はクリップの選択に戻る

## プリセット

| モード | 名前 | 主な値 |
|---|---|---|
| Guitar | Acoustic Strum | motion 8 分、down 30 ms、drift 12 ms |
| Guitar | Funk 16 | motion 16 分、down 12 ms、up 10 ms、up skip 2、legato 0 |
| Guitar | Ballad Arp | down 70 ms、up 50 ms、legato 80 % |
| Piano | Ballad | pedal chord、chord balance 70 %、drift 14 ms |
| Piano | Pop Tight | jitter 2 ms、groove のアクセントを 1.5 倍、pedal off |
| 共通 | Subtle | すべての量を初期値の半分 |

ヘッダーのプリセット名か ☰ で一覧を開く。一覧は Init（すべて初期値に戻す。モードと手での変更は残す）、組み込み、ユーザー（× で削除）の順に並べ、下に名前を付けて保存する欄を置く。◂ ▸ でも順に切り替えられる。ユーザープリセットは `storageDirectory/presets.json` に保存する。Re-apply は最後に使った設定を `storageDirectory/last.json` から読み、シード値だけ新しくする。

## UI（ADR-0008〜0011）

### 右クリックメニュー（MidiClip）

`humino…`、`humino: Re-apply`、`humino: Strum Down`、`humino: Strum Up`、`humino: Extract Groove`（v2）

### ダイアログ（960 × 720 px）

```
┌──────────────────────────────────────────────────────────┐
│ humino   [Guitar|Piano]   Acoustic Strum ◂▸  ☰   seed 042 ⟳ │ ヘッダー
├──────────────────────────────────────────────────────────┤
│   プレビュー（ミニピアノロール、Drift の曲線）              │
├──────────────────────────────────────────────────────────┤
│  ● groove   ● humanize   ● strum   connect                │ タブ
├──────────────────────────────────────────────────────────┤
│  drift     jitter     legato     vel ±     chord bal      │ パラメータ
│  12.0ms    4.0ms      60%        8         40%            │
├──────────────────────────────────────────────────────────┤
│  12 notes selected                  [ Cancel ]  [ Apply ]  │ フッター
└──────────────────────────────────────────────────────────┘
```

- パラメータは「ラベル（小）＋ 数字（大）＋ 小さなグラフ」。数字の上下ドラッグで変え、Shift で細かく、ダブルクリックで初期値に戻す
- Groove タブはパラメータ列の代わりに 16 本のステップ表を置く（上半分が timing、下半分が velocity）
- タブ名の左の丸ボタンで Groove、Humanize、Strum を on / off する（Strum はギターモードだけ）。off のタブは名前に取り消し線を引き、パラメータを薄くする。値は残るので、on に戻せば元の設定で効く。Connect のタブは 3 種類がすべて off のとき薄くする
- モードで使わないパラメータは隠す（ギターモードの spread と pedal、ピアノモードの strum とボイシング）。ピアノモードでは Strum タブを「pedal」と表示し、ペダルの設定だけを出す
- Connect タブは 3 種類を同じ列にそろえて並べ、velocity をどの行でも右端に置く
- 詳細な設定は Advanced として折りたたむ
- ダイアログ内の変更（パラメータ、プリセット、シード値、手での変更）は ⌘Z / Ctrl+Z で取り消し、⇧⌘Z / Ctrl+Y でやり直す。マウスを離した時点を 1 操作として数える
- ツールチップの説明文だけ、`Environment.language` が `"JA"` なら日本語

### プレビュー（ピアノロール）

- 使っている音程だけを行にする（Live の Fold と同じ）。左端に音名、上端に小節番号を出す
- 下にベロシティのレーンを置く。棒（`--velocity` の色）が処理後、横線が元の値
- ノートと棒は、ベロシティが強いほど濃く描く（Live と同じ）
- ピンチまたは ⌘ / Ctrl + スクロールで横に拡大、スクロールで左右に移動、空いた所のダブルクリックで全体表示
- ノートのクリックで和音を選択（Shift で追加）、空いた所のドラッグで範囲選択、空いた所のクリックで選択解除。ダイアログでの選択は、クリップ側の選択より優先して Apply に渡す
- ⌥ を押しながらノートをドラッグすると、そのノート（選択中なら選択したノートすべて）の位置を ms 単位でずらす。ベロシティのレーンを上下にドラッグすると、選択中のノート（なければ近くの和音）のベロシティを増減する
- ノートにカーソルを合わせると、処理ごとのずれ（ms）、ベロシティの変化、手での変更を表示する
- プレビューの下に選択中の和音の編集欄を置く：Lock / Unlock、stroke（auto / ↓ / ↑）、speed、up skip、Reset、Deselect。stroke、speed、up skip はギターモードだけ出し、Strum が off のときは押せない

### 手での変更（Overrides）

- 和音ごと（`chordKey` で識別）：stroke の向き、speed（ms）、up skip
- ノートごと（`noteKey` = 音程 + 和音の位置 で識別）：lock（元のまま残す）、dt（ms）、dv（ベロシティ）
- 手での変更は、全処理のあとに当てる。シード値や量を変えても、ずらした分は保たれる
- 元のノートと一緒に保存する（ADR-0002）。以前の保存形式の「向きの固定」は読み込み時に和音ごとの変更へ読み替える


- 元のノートをグレーの輪郭、結果のノートを白っぽい色で描く
- 開いているタブの処理で開始位置、長さ、ベロシティのどれかが変わったノートは、その処理の色で塗る（Strum タブは疑似ペダルの変化も含む）
- 元の位置からのずれを、処理ごとの色の線で積み重ねて描く。開いているタブの処理だけ濃くする
- Connect で足したノートはスカイ色で描く
- 処理対象でないノートは暗く描く

  --muted: #5e5e5e;      /* 線と面だけ。文字には使わない */
